# Pop-out icon

`window-pop-out-symbolic.svg` is copied unchanged from System76's COSMIC icon
collection, as packaged in Fedora cosmic-icon-theme 1.10.0-2.fc44.
Upstream: https://github.com/pop-os/cosmic-icons

This icon is licensed under Creative Commons Attribution-ShareAlike 4.0
International; the full license is in `LICENSE.window-pop-out`.
Deductum embeds it so the proof-window button remains visible when the desktop
or Flatpak SDK lacks the COSMIC icon theme. The symbolic handle uses the active
foreground colour; the geometry and existing rendered-button tests are unchanged.
